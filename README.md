# データサイエンス100本ノック 学習記録

## 概要

本リポジトリは、データサイエンティスト協会スキル定義委員が公開している「データサイエンス100本ノック（構造化データ加工編）」を用いた個人学習の記録です。

Pythonによるデータ加工・集計・可視化等の基礎技術を習得することを目的として、各演習問題に取り組んだ過程と解答を記録しています。

## 使用教材

データサイエンティスト協会スキル定義委員
「データサイエンス100本ノック（構造化データ加工編）」

公式リポジトリ：
https://github.com/The-Japan-DataScientist-Society/100knocks-preprocess

問題文、データセット、Docker環境等は上記教材を利用しています。これらの著作権・権利は、それぞれの原著作者・権利者に帰属します。

## 目的

・ pandasを中心としたデータ加工技術の習得
・ Pythonによるデータ分析の基礎力向上
・ Git / GitHubを利用した学習履歴・コード管理の習得

## 注記

本リポジトリは個人の学習記録として作成したものであり、「データサイエンス100本ノック（構造化データ加工編）」の公式リポジトリではありません。

演習問題に対する解答コードについては、自身の学習過程で作成したものを記録しています。
